## How to read a component, statement by statement

Start with its module, then follow one resolver method into its service and schema. Framework imports provide decorators and exceptions. Local DTO imports define the API's shapes; enum imports provide the exact persisted/public values; schema imports register persistence; service imports identify cross-component work. `import type` disappears at runtime. A `Model<T>` annotation describes the document type but does not register a provider: `MongooseModule.forFeature` and the matching `@InjectModel` name do that.

`@Module` imports make exported dependencies available, providers register injectable classes, controllers register HTTP handlers, and exports allow other modules to inject a service. Registering a Member model locally does not import MemberService. `@Injectable` lets Nest construct services. Constructor parameters store dependencies; `private readonly` permits using the injected instance within the class without replacing that reference. None of these decorators changes a domain's permissions by itself.

`@Resolver()` groups methods; `@Query` reads and `@Mutation` writes according to the existing API. The function in the decorator supplies the runtime GraphQL result type. `@Args('input')` supplies a client argument, while `@AuthMember('_id')` reads the identity placed in GraphQL context by a guard. `@UseGuards` protects an operation and `@Roles` supplies role metadata to RolesGuard. A TypeScript `Promise<Event>` describes asynchronous return values; it is separate from GraphQL's `@Mutation(() => Event)`. Public methods delegate; private methods perform reusable work inside that service.

In DTOs, `@InputType` defines accepted GraphQL objects and `@ObjectType` defines returned objects. `@Field(() => String)` exposes a field as String, including database IDs; the backend does not convert them to GraphQL ID scalars. `Int` is used for counters/quantities, Float for prices, Date for timestamps, and array functions for lists. `nullable: true` affects GraphQL, whereas `?` affects TypeScript. `!` tells TypeScript the property will be initialized by the framework. A class initializer or Field default affects creation/default construction and must not accidentally appear in an update class.

Validators describe separate constraints: IsString/IsEnum/IsMongoId check values; IsNotEmpty rejects empty strings; IsInt/Min/Max constrain pagination; IsArray and array-size/unique decorators constrain collections. Transform trims selected strings. Type constructs nested DTO instances and ValidateNested validates them. IsOptional skips both undefined and null. `ValidateIf(... value !== undefined)` skips omission but still rejects invalid null. This distinction is essential in Event/Faq/Equipment updates. The two new explicit update classes reproduce it without mapped-type inheritance.

For persistence, each default-exported `schemas/*.model.ts` uses raw `new Schema`, just like Nestar, with field types, defaults, enums, refs, indexes and collection options. GraphQL object types are not Mongoose schemas. `findOne` reads, `create` inserts, conditional `findOneAndUpdate` updates and can return the updated record, `findOneAndDelete` hard-deletes, `$inc` modifies counters, `lean` returns plain objects, and `exec` executes a query. Aggregation `$match/$sort/$facet` builds list and count in one response; skip/limit apply only to list. `metaCounter` is an array of TotalCounter, including an empty array for zero matches; it is not a scalar total.

`getAllMembersByAdmin` lists with admin filters; `updateMemberByAdmin` retains the original privilege/type restrictions. `promoteMemberToInstructor` requires a caller session and the matching approved application snapshot, applies instructor fields conditionally, and is called from application approval. `updateInstructorProfile` updates only instructor-profile fields, verifies a supplied Resort, preserves nullable association/prices, and refreshes accessToken. `generalProfileFields` excludes instructor-specific fields rather than applying the DTO wholesale.
